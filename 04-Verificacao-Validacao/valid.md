# Validação

A validação busca identificar se o produto em desenvolvimento está correto. Essa atividade permite avaliar se o produto atende às necessidades dos usuários e resolve os problemas identificados durante o processo de levantamento de requisitos e regras de negócio com os stakeholders.

A organização das viagens e a redução do trabalho manual serão utilizadas como exemplo da validação. Para realizar a avaliação, o sistema poderá ser utilizado por estudantes, administradores e motoristas, visando representar situações reais de uso. Os estudantes farão as reservas, os administradores poderão acompanhar a demanda e a distribuição dos passageiros, enquanto os motoristas terão acesso às informações referentes à viagem.

Após o período de teste monitorado, será possível avaliar se o sistema facilita a organização do transporte, centraliza as informações e atende às necessidades da operação. A etapa de monitoramento é fundamental para obter feedbacks sobre as funcionalidades, que, por sua vez, fornecem dados suficientes para identificar se o produto realmente resolve o problema estabelecido no início do projeto.
