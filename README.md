# Projeto Integrador — Fundamentos de Engenharia de Software

## Nome do sistema
Transporte Universitário

## Objetivo
Propor uma solução de software para a organização
de transportes no âmbito universitário.

## Funcionalidades principais
- Cadastrar usuários
- Permitir o gerenciamento dos passageiros
- Registrar dias e horários das viagens
- Permitir a seleção das faculdades e univerdidades de destino
- Distribuir passageeiros entre ônibus disponíveis conforme a capacidade do veículo
- Informar aos passageiros qual ônibus deverão utilizar e suas informações de horário
